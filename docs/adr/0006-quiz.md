# A Quiz is a finite scored pass

A Topic's recall is a Quiz over Definitions, Techniques, and Theorems, and not over Problems. Each content Subtopic has a Quiz after Theorems and before Problems. The last Subtopic of the Topic is a Quiz over every Definition, Technique, and Theorem in the Topic, and it holds no kinds of its own. Each question is an authored list of parts plus a map from part index to wrong answers, so a later copy of a symbol can be a blank while an earlier copy stays visible. Easy through Mastery hide a fraction of those indexes and offer the part text among the wrong answers. Yuxiang hides the statement and scores typed LaTeX by the cosine similarity of OpenRouter embeddings.

## Considered Options

- An infinite matching of Definitions to statements. Rejected: a Quiz is one shuffle and a score, then it can be started again.
- A separate name for the Subtopic pass. Rejected: both passes are a Quiz.
- Inferring atoms from the notes. Rejected: the author chooses which copy is a blank and which strings are the wrong answers.
- Scoring Yuxiang by comparing atoms. Rejected: Yuxiang is the similarity of the typed LaTeX to the joined parts.
